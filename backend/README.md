# Learnova LMS

Learnova LMS is a learning management system backend built with Python, Django, Django REST Framework, and PostgreSQL.

This project is being developed as a practical learning project aligned with the Django development curriculum.

## Planned Features

- Custom user model and role-based permissions
- Course and category management
- Course sections and lessons
- Student enrollment and lesson progress tracking
- RESTful APIs and JWT authentication
- Filtering, searching, and pagination
- OpenAPI schema and Swagger UI
- Automated tests
- Environment-based configuration

## Technology Stack

- Python
- Django
- Django REST Framework
- PostgreSQL
- Psycopg
- Simple JWT
- django-filter
- drf-spectacular
